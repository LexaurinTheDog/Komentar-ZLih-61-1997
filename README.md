# Komentář k zákonu č. 61/1997 Sb., o lihu (zákon o lihu)

Otevřený komentář k zákonu o lihu — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; podmínky výroby a úpravy lihu, výroba lihovin, pěstitelské pálení, výrobní zařízení a měření lihu, zušlechťování a denaturace, druhy lihu, uvádění do oběhu, evidence, oznamovací povinnost a přestupky.

Konsolidované znění: dokument e-Sbírky `SB-1997-00061_2025-07-01`.
